# BI-05：运行中追加、停止和继续

**What to build：** 看到真实任务状态，排队需求、停止任务并继续工作。

**Blocked by：** BI-02 固定悬浮输入框完成真实对话

**Status：** complete；队列、停止、备注和失败路径自动验收通过

- [ ] 复用现有队列；完成后执行、编辑取消和仅记备注均真实生效。
- [ ] 停止并修改等旧任务结束；停止失败可重试，不启动重复修改。
- [ ] 无可靠分母不显示百分比和剩余时间；移除假进度。
- [ ] 状态变化不重建输入框；验证正常完成、停止竞争和工具失败。
- [ ] 遵守整合计划的共同验收标准，提交真实操作证据。
