# BI-10：真实仿真与过期结果查看

**What to build：** 打开受支持结果、调整后处理，并知道是否对应当前设计。

**Blocked by：** BI-01 打开真实 STEP，进入新版工作台

**Status：** complete；真实结果元数据、过期状态和错误输入自动验收通过

- [ ] 复用结果读取与求解能力；量名、单位、色标和统计来自真实结果。
- [ ] 接已有量切换、切片或探查；显示设置和求解参数分开。
- [ ] 保留按需准备与分析入口；缺组件、取消和失败可恢复。
- [ ] 模型变化提示过期；真实结果和错误输入均验证，未支持选项禁用说明。
- [ ] 遵守整合计划的共同验收标准，提交真实操作证据。
