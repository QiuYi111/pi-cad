# BI-06：预览并应用真实参数修改

**What to build：** 选择有绑定部位，在新版面板修改、预览、重置并应用参数。

**Blocked by：** BI-01 打开真实 STEP，进入新版工作台

**Status：** complete；预览、迟到响应、失败、重置和应用自动验收通过

- [ ] 复用现有绑定和授权应用，显示单位、范围与已应用值。
- [ ] 无绑定提供对象引用入口，不伪造任意 STEP 调参。
- [ ] 迟到预览不覆盖新值；应用后几何和版本一致。
- [ ] 面板可关闭恢复，缩放不截断数值与按钮；用真实孔径核验。
- [ ] 遵守整合计划的共同验收标准，提交真实操作证据。
