# BI-03：拖动输入框并恢复位置

**What to build：** 拖动细线调整位置，缩放窗口和重启后继续使用。

**Blocked by：** BI-02 固定悬浮输入框完成真实对话

**Status：** complete；拖动、保存、缩放、复位专项通过

- [ ] 点击切换与拖动不误触；双击重置不触发两次切换；提供键盘重置。
- [ ] 按窗口比例保存并限制边界；最大化、短窗口、高缩放、跨屏和异常存储可恢复。
- [ ] 动画起点跟随输入框实际位置，输入框本体不动。
- [ ] 指针取消或失焦后不粘住；默认位置不挡关键操作；主动移动后可重置。
- [ ] 遵守整合计划的共同验收标准，提交真实操作证据。
