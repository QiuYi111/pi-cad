# UX-03：替换生硬的对话弹出列表，采用 ChatGPT 式历史侧栏

**What to build:** 用户在 ChatGPT 式侧栏新建、查找、切换和改名对话。

**Blocked by:** UX-02

**Status:** ready-for-agent

- [ ] 移除聊天标题栏里隐藏历史的更多按钮及狭窄弹出列表；历史放在左侧，当前对话与项目关系一眼可辨。
- [ ] 对话行以标题为主，日期分组；重命名等操作收进悬停或键盘可达的更多菜单，避免每行固定堆叠评分、时间和按钮。
- [ ] 顶部固定“新对话”和搜索；支持搜索当前项目会话，明确标注搜索范围；无结果可清除搜索。
- [ ] 项目下展开其会话；切换项目后列表刷新且不闪现上一项目内容，加载与失败不伪装成空历史。

- [ ] 明确区分项目与会话；当前会话高亮，按日期分组，长标题截断但可查看全名。
- [ ] 新对话无需立即启动 Agent；真实会话持久化，改名跨重启保留；菜单支持键盘与取消。
- [ ] 切换后消息、附件与成果归属正确，迟到请求不串项目；空、加载、失败均有状态。
- [ ] 附真实操作和视觉证据；未执行项明确标记，不用已有测试通过代替本票验收。
