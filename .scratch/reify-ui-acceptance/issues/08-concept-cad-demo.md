# UX-08：从概念方案完成真实参数建模

**What to build:** 通过桌面 UI 创建 Demo 项目，确认概念方案，得到可查看和调参的真实 CAD。

**Blocked by:** UX-01、UX-04

**Status:** ready-for-agent

- [ ] 概念图必须由真实图像能力生成或用户导入；缺能力如实记录，不能用示例图冒充生成。
- [ ] 建模完成后验证真实几何、尺寸、单位、旋转、缩放、剖切；成果自动切换不抢输入和阅读焦点。
- [ ] 预览、重置、应用有效；故意越界后保留上一模型，可修复并导出重新打开。
- [ ] 运行中追加、停止、继续至少各执行一次；记录等待、反馈与失败恢复。
- [ ] 附真实操作和视觉证据；未执行项明确标记，不用已有测试通过代替本票验收。
