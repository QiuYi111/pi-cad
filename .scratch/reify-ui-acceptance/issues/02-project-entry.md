# UX-02：参考 ChatGPT 重建左侧导航，显露项目入口

**What to build:** 用户从常驻、可折叠侧栏找到新建项目和打开项目，进入真实工作区。

**Blocked by:** 无，可立即开始

**Status:** ready-for-agent

- [ ] 修复当前创建入口藏在画布项目下拉中、对话模式难以发现的问题；左侧导航直接显示“新建项目”和“打开项目”，无需先切换画布。
- [ ] 参考 ChatGPT 的导航层级：顶部新对话与搜索，中部项目及历史，底部设置；使用 Reify 品牌和视觉，不照搬 ChatGPT 品牌。
- [ ] 侧栏可折叠；对话、画布、设置、工作流和记录页均有明确的展开入口与当前位置，避免重复顶部导航和第二套项目菜单。

- [ ] 两次点击内打开创建表单；名称、位置、取消、同名、不可写路径有完整处理。
- [ ] 最近项目来自真实记录；可切换、移除失效记录，重启恢复；运行中切换遵守现有任务约束。
- [ ] 画布模式、设置页和短窗口都能找到项目入口；复用现有品牌资产，与参考稿逐项对照。
- [ ] 附真实操作和视觉证据；未执行项明确标记，不用已有测试通过代替本票验收。
