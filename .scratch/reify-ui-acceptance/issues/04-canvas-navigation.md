# UX-04：折叠侧栏并保持悬浮输入框

**What to build:** 从对话进入大画布，侧栏可折叠，输入框始终稳定可用。

**Blocked by:** UX-02、UX-03

**Status:** ready-for-agent

- [ ] 切换十次不移动或重建输入框；草稿、附件、焦点、历史滚动、相机和选择保留。
- [ ] 拖动与点击不误触，双击和键盘可复位；位置按窗口保存并限制边界。
- [ ] 1366×768、1920×1080、920×680及125%/150%缩放检查；不遮挡关键按钮，减少动画模式可用。
- [ ] 附真实操作和视觉证据；未执行项明确标记，不用已有测试通过代替本票验收。
