# UX-05：清除设置页旧 Vercel 风格，重做配置布局

**What to build:** 用户在统一视觉的设置页选择项目、模型、审查方式并保存，完成登录和运行环境检查。

**Blocked by:** 无，可立即开始

**Status:** ready-for-agent

- [ ] 明确移除旧黑底、深灰表单、蓝色强调、重复描边卡片和过小标签；不是仅替换背景色。
- [ ] 设置按项目、账号与模型、运行环境、高级选项分组；采用清晰的栏目与表单行，减少等大卡片堆叠，主要操作位置稳定。
- [ ] 输入框、下拉、登录状态、安装进展、错误、保存反馈、焦点和禁用状态全部使用同一套 Reify 视觉。
- [ ] 展开所有设置分组和下拉后截图检查，不能只验收页面首屏；长路径和错误文字完整可读。

- [ ] 统一暖白、石色、深绿、字体及控件，替换黑色卡片和蓝色强调色；基础设置与高级设置分组。
- [ ] 保存有成功、失败及未保存反馈；切页与再次打开不丢状态，保存失败不显示成功。
- [ ] 真实登录、取消、重试和已有登录分别验证；依赖检查显示实际状态，安装期间可见进展与失败恢复。
- [ ] 附真实操作和视觉证据；未执行项明确标记，不用已有测试通过代替本票验收。
