# UX-06：清除工作流页旧 Vercel 风格，重做流程浏览与编辑

**What to build:** 用户从新版工作流页选择流程、查看阶段、保存自定义流程并用于新任务。

**Blocked by:** 无，可立即开始

**Status:** ready-for-agent

- [ ] 移除黑色流程库、蓝色选中阶段、黑色 YAML 编辑区、密集标签卡片；阶段选中、按钮、弹窗及错误使用 Reify 暖白、石色、深绿。
- [ ] 页面以选择流程、理解阶段、查看规则为主；源码编辑按需展开，不能默认占据半屏迫使普通用户读 YAML。
- [ ] 流程列表、阶段路径、详情和保存/采用操作层次清楚；长流程在局部滚动，页面本身不被撑宽。
- [ ] 为列表、选中阶段、源码展开、校验失败、保存成功和采用状态分别留视觉证据。

- [ ] 流程列表、阶段图和详情符合统一视觉；源码按需展开，短窗口无整页横向溢出。
- [ ] 保存校验错误可定位；保存后选中正确的 ID 与版本，再次打开一致。
- [ ] 采用流程只影响新任务；已有任务版本不变，空列表、读取失败有下一步。
- [ ] 附真实操作和视觉证据；未执行项明确标记，不用已有测试通过代替本票验收。
