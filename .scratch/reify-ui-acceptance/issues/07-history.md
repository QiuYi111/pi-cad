# UX-07：清除记录页及评价面板旧 Vercel 风格

**What to build:** 用户在新版记录页查看真实会话与工具结果，提交评价，检查经验候选。

**Blocked by:** 无，可立即开始

**Status:** ready-for-agent

- [ ] 移除黑色记录列表、深色气泡、蓝色选择框、黑色评分和经验浮窗，统一 Reify 的文字、表单、边框、颜色及阴影。
- [ ] 默认优先展示可读记录，评分与经验处理按需展开；避免底部常驻密集控件挤压列表。
- [ ] 对话历史负责继续工作，记录页负责回看与评价；导航名称和说明清楚区分两者。

- [ ] 列表、搜索、阅读区和评价统一视觉；工具详情按需展开，长内容可读，快速切换不显示旧请求结果。
- [ ] 空、加载、读取失败、无搜索结果各自明确；评价保存后能再次读取。
- [ ] 经验处理不显示假百分比；真实候选、验证、采用状态明确，未验证不可采用。
- [ ] 附真实操作和视觉证据；未执行项明确标记，不用已有测试通过代替本票验收。
