# 02: 完成 API key 配置链路

**What to build:** 用户可为任意 Prime API key 提供商填写、保存、替换、检查和删除凭据，并立即看到该提供商及模型变为可用或不可用。

**Blocked by:** 01: 接入 Prime 原生模型目录。

**Status:** ready-for-agent

- [ ] API key 通过主进程交给 Prime `AuthStorage` 持久保存，沿用 Prime 的文件锁、原子写入和文件权限。
- [ ] 保存后刷新认证状态和可用模型；失败时显示具体错误，不能显示虚假成功。
- [ ] 已保存的密钥不回传 renderer，不出现在日志、命令行、项目文件或普通设置文件中。
- [ ] 用户可替换密钥，也可只删除当前提供商的存储凭据；不能删除整个认证文件。
- [ ] 区分存储、环境变量、运行时和自定义模型配置等认证来源；环境变量凭据不得伪装成可由界面删除。
- [ ] Azure、Cloudflare 等需要额外字段的提供商不能被误判为只填一个 key 即配置完成。
