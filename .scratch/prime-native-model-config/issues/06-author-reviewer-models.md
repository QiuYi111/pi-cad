# 06: 统一 Author 与 Reviewer 模型配置

**What to build:** 用户为 Author 和 Reviewer 分别选择默认模型及推理等级，两者共享同一套 Prime 模型目录、收藏和凭据。

**Blocked by:** 05: 加入收藏、默认模型和快速切换。

**Status:** ready-for-agent

- [ ] Author 与 Reviewer 使用同一个动态模型选择控件，不再使用独立自由文本或硬编码提供商。
- [ ] 两个角色可保存不同的默认模型和推理等级。
- [ ] 认证状态和凭据按提供商共用，不能因角色不同重复登录。
- [ ] 选择不可用模型时进入对应认证流程；取消后保留原选择。
- [ ] Reviewer 继承、固定模型和显式关闭等现有语义有清楚且可恢复的界面状态。
- [ ] 重启应用及恢复会话后，两个角色的选择与实际运行模型一致。
