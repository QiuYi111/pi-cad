# 05: 加入收藏、默认模型和快速切换

**What to build:** 用户可从完整目录收藏常用模型、排序、设置默认模型，并在对话中快速切换；配置沿用 Prime 的模型范围机制。

**Blocked by:** 01: 接入 Prime 原生模型目录；02: 完成 API key 配置链路；03: 完成通用 OAuth 登录链路。

**Status:** ready-for-agent

- [ ] 收藏列表保存精确的提供商、模型 ID 和该模型支持的推理等级，并映射到 Prime `enabledModels/scopedModels`。
- [ ] 用户可添加、删除和排序收藏；快速切换只遍历收藏模型。
- [ ] 用户可设置新会话默认模型和默认推理等级，并写入 Prime 原生默认模型配置。
- [ ] 切换当前模型立即生效，但不修改新会话默认模型。
- [ ] 收藏可包含暂未认证模型并明确标识；切换时进入对应 API key 或 OAuth 配置。
- [ ] 恢复会话优先恢复该会话原模型；删除收藏不强制改变正在运行的会话。
- [ ] Prime 的校验、推理等级限制和默认回退规则保持有效。
