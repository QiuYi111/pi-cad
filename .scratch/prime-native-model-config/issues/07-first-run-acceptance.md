# 07: 统一首次启动并完成真实验收

**What to build:** 新用户无需理解 Prime 配置文件，即可在首次启动中选择任意受支持提供商、完成认证、选择模型并开始第一段对话。

**Blocked by:** 02: 完成 API key 配置链路；03: 完成通用 OAuth 登录链路；04: 支持高级与自定义提供商配置；05: 加入收藏、默认模型和快速切换；06: 统一 Author 与 Reviewer 模型配置。

**Status:** ready-for-agent

- [ ] 首次启动根据所选提供商显示正确的 API key、OAuth 或高级配置流程，不再默认要求 ChatGPT 登录。
- [ ] 完成认证后只能选择该提供商实际可用的模型，并可同时设置默认模型与推理等级。
- [ ] 旧的 Reify 模型设置可迁移；无效 provider ID 和模型 ID 有明确恢复路径。
- [ ] 重启应用、创建新会话和恢复旧会话后，默认、当前及恢复模型符合 Prime 原生优先级。
- [ ] 在干净 Windows 安装环境中真实验证 API key、OAuth、收藏切换、退出登录和失败重试。
- [ ] 自动测试覆盖目录刷新、凭据隔离、秘密不泄漏、OAuth 完成判定、推理等级约束和设置持久化。
