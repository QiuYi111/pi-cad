# Reify Computer Use 验收方案
日期：2026-09-06
状态：方案已确认，尚未执行。后续 UI 开发和最终包按本方案验收。

## 执行规则
- 使用真实安装版、真实运行时、真实文件，通过可见界面点击、输入和拖动。
- 自动测试、RPC、日志和文件核验作为补充；不能代替真实桌面流程。get_state 成功只证明运行时响应，不能证明模型请求或账号有效。
- 测试使用独立 Windows 用户或独立配置。启动后核对实际配置路径，检查正式配置测试前后一致，防止临时项目污染。
- 每一步记预期、实际、截图、耗时、通过/失败/受阻；不可用工具和缺组件不算通过。
- 不承诺一次 Demo 覆盖全部边界；主流程、故障专项、窗口专项分别执行。

## Demo：参数化电机支架
输入：设计 6061 铝合金电机支架。底板 80×60×6 mm，立板 60×50×5 mm，中心孔直径 36 mm，四个 M4 安装孔分布于直径 48 mm 的圆，底板两个 6×18 mm 长孔，内角 R4。承受 120 N 水平载荷，目标最大位移低于 0.3 mm、安全系数大于 2。先给两个概念方案，确认后建模。
执行前让 Agent 澄清制造方式、孔位、安装间隙、固定面、载荷方向和作用区域。尺寸如有冲突，先提示并修正，不默默猜测。分析阈值是目标，是否满足由真实结果判断。

1. 创建独立 Demo 项目；概念图比较、缩放、圈选和引用。
2. 确认方案，真实建模；旋转、缩放、测量、剖切及成果身份核对。
3. 中心孔改为 40 mm，预览、重置再应用。
4. 尝试 70 mm 孔，检查几何失效或约束警告；不能预先假定一定报错，应核查剩余材料。
5. 恢复 40 mm；立板厚度改为 6 mm，继续建模。
6. 确认边界条件后运行结构分析，查看位移、应力、单位和来源。
7. 再改厚度，验证旧结果过期，并重算新版本。
8. Blender 预览、外部打开、修改、保存、返回刷新。
9. 比较、恢复版本，检查批准过期，重新审查和批准。
10. 本地导出 STEP 和交付记录，重新打开核对尺寸及版本。

## 独立检查
- 安装：图标、入口、首启、登录取消重试、重开、升级、回退、卸载后项目保留。
- 导航：两次点击内找到新建表单；打开项目、最近项目、会话新建切换改名和重启恢复。
- 输入框：下半屏悬浮；切换十次位置尺寸不变；拖动、双击及键盘复位；保留草稿附件和焦点。
- 任务：追加需求、备注、停止、继续，观察进展，不显示假完成和假百分比。
- 视图：CAD、概念图、仿真、Blender 之间切换保留合理状态；自动切换不抢焦点。
- 故障：失效项目目录、损坏 STEP、运行时失败、参数越界、缺仿真组件、缺 Blender、未保存返回、不可写导出目录、运行中切项目。
- 设置：项目、模型、审查、登录、运行环境、保存失败反馈。
- 工作流：阶段、编辑、校验、保存、采用，新旧任务版本隔离。
- 记录：搜索、阅读工具结果、评分、经验候选与验证。
- 窗口：1366×768、1920×1080、920×680，125%和150%缩放；最大化/还原、键盘导航、减少动画。

## 视觉证据与通过标准
每个关键页面在相同窗口尺寸下与参考稿对照：首启、侧栏、空对话、概念图、CAD、参数、仿真、设置、工作流、记录、错误、交付。
使用现有品牌资产和用户确认的原型，统一暖白、石色、深绿；检查黑色旧面板、蓝色强调色、文字对比、弹窗、菜单和禁用状态。
保存截图和操作记录；能录屏则附录屏。视觉偏差逐项记录，不能凭测试通过声称与稿一致。
最终包必须从安装走到真实导出，无阻断、无丢数据、无假成功；未完成项保留待验收。至少一名未参与开发的工程师独立试用。
