# Reify Windows 内测整合票草案

日期：2026-09-06。状态：待确认拆分，未发布或开工。

目标：安装后的新版 App 完成真实工程流程，交付可进入内测的 Windows 包。本轮补界面接入与验收，不重做内核，不把既有 38 票全部重新开发。

## 现有依据

- 总计划：../reify-development-plan.zh-CN.md；原票：../reify-development-slices/。
- 已核实品牌资产：docs/assets/reify-mark.svg、reify-lockup.svg，桌面 build 的 SVG/PNG/ICO，以及 BrandMark、Wordmark 组件。复用并核对版本，不重做 LOGO。
- 视觉稿：C:/Users/Admin/Downloads/reify_designs/final_prototype 的六张 PNG。首次接入固定副本或哈希。
- 最新交互优先：大画布、唯一输入框、下半窗口悬浮、可拖动、切换时输入框不动；对话在其背后展开。原型裁图、假数值及整页重建逻辑不能直接搬入产品。
- 复用 Agent、IPC、真实 Viewer、参数、概念画板、仿真、Blender、版本与批准能力。必要整理放入首次使用该能力的行为票。

## 内测边界

Windows x64 + 明确实测的 WSL 环境，具体版本在 BI-13 固定。已有 WSL 为首条保证路径；无 WSL 的干净系统需另有实测证据。Mac/Linux 发布、组织身份接入和量化收益按原票追踪，不阻塞本批 Windows 内测。

BI-14 交付主流程候选包；BI-15 交付完整声明范围的内测包。多成果和已有企业入口都要接入，不无声删除现有功能以缩短排期。环境不支持的能力明确限制；若要缩小范围，应明确调整范围及依赖，不能把失败票当完成。

## 共同完成标准

- 前置全部完成才开工。一票一个可独立演示的用户行为，贯穿实际需要的状态、真实执行、界面、持久化及失败恢复。
- 使用安装后或正式 Electron 的真实数据页面。构建成功、原型截图和按钮存在不能单独证明完成。
- 1366×768、1920×1080；Windows 100%、125%、150% 缩放；一个短窗口。记录实际可用尺寸与缩放，检查中文长文本、键盘焦点及减少动画。
- 视觉按参考稿检查资产、颜色、字体、间距与面板比例；新交互按最新需求。模型用真实视角、光照和背景检查，不以裁图制造匹配。
- 每票检查适用的空、加载、失败与恢复。截图记录状态，录屏检查动画中间过程、快速切换及输入框稳定性。
- 保存代码版本、环境、步骤、相关测试和产物身份；不把历史测试数字冒充本轮证据。不记录凭据；Python 使用 uv run python。
- 功能、视觉、安装验收分别记录。主要操作被挡、丢草稿、串项目、错误成果、假成功、不可恢复错误均阻断交付。

## 依赖与交付

1. [BI-01 打开真实 STEP，进入新版工作台](01.md) — 前置：无。复用现有标志、字标、图标和真实 Viewer；新工作台打开、旋转、缩放、导出 STEP。

2. [BI-02 固定悬浮输入框完成真实对话](02.md) — 前置：BI-01。用户用同一输入框发送需求、查看真实回复，切换完整对话和画布。

3. [BI-03 拖动输入框并恢复位置](03.md) — 前置：BI-02。拖动细线调整位置，缩放窗口和重启后继续使用。

4. [BI-04 首个真实成果接管画布](04.md) — 前置：BI-02。从空项目一句需求得到真实 CAD，自然进入画布并继续修改。

5. [BI-05 运行中追加、停止和继续](05.md) — 前置：BI-02。看到真实任务状态，排队需求、停止任务并继续工作。

6. [BI-06 预览并应用真实参数修改](06.md) — 前置：BI-01。选择有绑定部位，在新版面板修改、预览、重置并应用参数。

7. [BI-07 修改失败后定位并修复](07.md) — 前置：BI-04、BI-06。保留上一可用模型，改值重试或让 Agent 修复失败修改。

8. [BI-08 切换项目、会话和重启恢复](08.md) — 前置：BI-04、BI-05。新版导航打开、新建、命名和切换真实项目与会话，重启后继续。

9. [BI-09 概念图比较并引用到对话](09.md) — 前置：BI-02。查看真实概念图、缩放圈选，并把选定方向用于下一条需求。

10. [BI-10 真实仿真与过期结果查看](10.md) — 前置：BI-01。打开受支持结果、调整后处理，并知道是否对应当前设计。

11. [BI-11 Blender 编辑后返回刷新](11.md) — 前置：BI-01。在新版预览场景，打开外部 Blender，保存后返回更新。

12. [BI-12 新版版本、批准和交付入口](12.md) — 前置：BI-01。找到已有比较、恢复、审查和批准能力，完成真实本地交付。

13. [BI-13 首次启动登录并准备项目](13.md) — 前置：无。内测用户完成环境检查、真实登录和项目选择，进入工作区。

14. [BI-14 安装候选包完成主流程](14.md) — 前置：BI-03、BI-07、BI-08、BI-13。安装 Windows 候选包，建模、改参数、失败恢复、导出并继续旧项目。

15. [BI-15 最终验收并交付内测包](15.md) — 前置：BI-09、BI-10、BI-11、BI-12、BI-14。交付可核验的 Windows 安装包、使用范围、已知限制和反馈方法。
