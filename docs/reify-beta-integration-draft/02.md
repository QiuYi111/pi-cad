# BI-02：固定悬浮输入框完成真实对话

**What to build：** 用户用同一输入框发送需求、查看真实回复，切换完整对话和画布。

**Blocked by：** BI-01 打开真实 STEP，进入新版工作台

**Status：** draft — 待确认拆分，未发布。

**验收条件：**

- [ ] 接真实 Agent，不带假项目和示例消息。
- [ ] 输入框在窗口下半部，切换全程位置和尺寸不变；对话在其背后展开。
- [ ] 草稿、附件、焦点、滚动、视角和选择保留；快速反复切换无闪白。
- [ ] 统一快捷键和提示；替换旧三档顶部模式导航；键盘和减少动画可用。
- [ ] 遵守本目录 README 的共同验收标准，提交真实操作证据。

**实施边界：** 先做必要的小范围整理，复用现有能力并保护已有改动。交付完整用户行为，超出一次开发上下文则按行为继续拆分；不拆成纯界面或纯后端票。
