# 04：概念图画板与选图继续设计

**状态：** 已完成。

**当前进展（2026-09-06）：**

- 图片经 Electron 原生解码并检查尺寸后才进入对话；损坏、伪装或超大图片会在输入区明确报错，用户可随时上传图片替代生成。
- 概念画板支持缩放、平移、并排比较、区域框选、逐图批注、过期/恢复与方向确认，状态在概念图和模型画布切换时保留。
- 方向确认将图片版本、归一化区域和批注送入同一对话并触发 CAD；生成图和上传图保持来源标识。
- 桌面 E2E 覆盖概念生成到 CAD、旧图禁用和恢复、选区与批注保留，并继续跑完模型、仿真、工作流、轨迹和设置回归。

**交付结果：** 用户上传或生成概念图，在画板比较、圈选并让 Agent 基于选定方向继续。

**前置依赖：** 03 对话与画布平滑切换。

**验收条件：**

- [x] 真实图片解码成功后才登记成果；伪 PNG、损坏图片明确拒绝；生成不可用时可上传继续。
- [x] 支持缩放、平移、并排、批注和选定方案；引用带图片版本与区域，反馈进入同一对话。
- [x] 修改需求后旧图保留为历史并标记不适用，新图可重新提交；选图后真实生成 CAD，来源可追踪。
- [x] 遵守总计划的共同完成标准，提交真实操作证据与相关失败验证。

**范围限制：** 不把概念图当作可测量 CAD，不建设绘图软件。

**开发方式：** 先核对已有实现与未合并修改；沿上述用户行为打通所需状态、真实执行、界面和测试。必要整理先做且保持原行为；不要另拆为纯前端或纯后端票。若一个独立上下文无法完成，按可演示行为继续拆分。

**演示：** 从用户入口执行“交付结果”，展示成功成果、一个相关失败及恢复；以验收中的实际数据核对结果。
