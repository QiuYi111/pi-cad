# 13：导入仿真结果并查看

**状态：** 已完成（2026-03-10）。

**交付结果：** 用户打开一个受支持的真实仿真结果，在同一画布切换物理量与图例。

**前置依赖：** 12 工具结果直接进入成果列表。

**验收条件：**

- [x] 首版选一种现有后端结果格式并公开支持范围；加载网格、单位、量名及模型来源。
- [x] 颜色范围、网格显隐和变形倍数只改变显示，不触发求解；错误文件可恢复。
- [x] 固定结果验证极值、单位和图例；切回 CAD 保留各自视角，来源不明时明确显示。
- [x] 遵守总计划的共同完成标准，提交真实操作证据与相关失败验证。

**范围限制：** 不一次支持所有求解器格式。

**开发方式：** 先核对已有实现与未合并修改；沿上述用户行为打通所需状态、真实执行、界面和测试。必要整理先做且保持原行为；不要另拆为纯前端或纯后端票。若一个独立上下文无法完成，按可演示行为继续拆分。

**演示：** 从用户入口执行“交付结果”，展示成功成果、一个相关失败及恢复；以验收中的实际数据核对结果。

**实现与证据：**

- 首版桌面元数据契约明确支持 ASCII VTK XML UnstructuredGrid `.vtu`；读取点/单元数、边界、point/cell 量、分量、极值、单位及 `model_source`。其他格式给出明确错误，完整 ParaView 仍保留已有广格式入口。
- 嵌入式 ParaView 真实加载数据并提供物理量、颜色最小/最大值、Surface/Edges/Wireframe/Points 和变形倍数；这些控件只更新 mapper、actor 或 warp filter，不调用求解器。
- 固定四面体结果验证 4 点、1 单元、应力 `10–82 MPa`、位移 `0–0.34 mm` 和模型来源；不支持的 STEP 输入先失败，随后合法 VTU 可正常读取。
- CAD 与仿真视图保持挂载，来回切换不会重建各自相机；来源缺失时明确显示 `Model source · unknown`。桌面 E2E 验证量名、极值、单位、来源和切回 CAD。
