# 10：装配中的选择与局部修改

**状态：** 已完成。

**当前进展（2026-09-06）：**

- STEP 可携带 schema 1 assembly identity manifest，以稳定 partId 将多个 solid 归为一个零件，并以 solidId 区分实体；同名零件仍由 ID 唯一识别。
- 无 manifest 时使用确定性几何键并明确显示 Unbound solid，避免把展开序号伪装成业务身份。
- Viewer 装配树支持选择、隐藏、隔离、取消隔离和整体恢复；引用包含零件名、partId 与模型 SHA-256 版本并进入同一 Agent 对话。
- 真实三实体测试覆盖双实体零件加另一同名零件；重建只改变 pin，frame 两个实体网格逐值不变且所有身份保持。完整桌面 E2E 覆盖树操作和重建后引用保持。

**交付结果：** 用户选择、隐藏或隔离一个零件，引用它让 Agent 修改正确对象。

**前置依赖：** 08 选择已有参数并预览修改。

**验收条件：**

- [x] 零件身份不依赖展开顺序或 solid 数量；多实体零件、重名零件可区分。
- [x] 支持装配树、选择、隐藏、隔离和整体恢复；引用显示零件与版本。
- [x] 用一个双实体零件加另一零件的装配验证，修改、重建后没有选错对象，变化仅作用于指定零件。
- [x] 遵守总计划的共同完成标准，提交真实操作证据与相关失败验证。
