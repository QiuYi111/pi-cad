# 01：打开 STEP，进入大画布

**状态：** 已完成。

**当前进展（2026-09-06）：**

- STEP 网格结果现在带源文件 SHA-256，画布显示文件名和短哈希。
- 已打通“导出副本”的桌面界面、IPC 和 Windows/WSL 路径复制。
- 打开另一 STEP 失败时保留当前模型，并显示可见错误。
- 已落实暖白大画布、深绿控件、居中模式切换和底部悬浮输入；无成果时显示完整对话。
