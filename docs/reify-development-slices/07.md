# 07：项目与对话切换后恢复

**状态：** 已完成。

**当前进展（2026-09-06）：**

- runtime snapshot 在 Renderer 重载后恢复主进程状态与当前会话消息；最后模型、草稿、工作区模式和画布类型均按项目保存。
- 自动会话标题可改为项目级别名；新建和切回旧对话会恢复各自消息。
- 单 Agent 限制在运行中项目切换时明确提示且拒绝切换，避免改变活动任务工作目录；项目队列、草稿、消息和模型互不串联。
- 中断状态提供继续任务和重试 runtime 两个入口；继续从最后持久工程状态启动。桌面 E2E 覆盖重载、两个项目、多对话、重命名和中断恢复。

**交付结果：** 用户新建、命名和切换对话，离开运行任务再返回，看到对应模型与进度。

**前置依赖：** 03 对话与画布平滑切换；05 停止任务并继续工作。
