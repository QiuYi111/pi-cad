# Pi-CAD investigate

Current state: INVESTIGATE (read-only).

Form a spatial or engineering hypothesis, then answer it with deterministic probes. Visual questions become targeted measure/frame/section checks. cad_simulate is available read-only when a quantitative physical hypothesis must be tested; cad_optimize is not available here. If more probing is needed call cad_transition(event="more_probe"). When the cause is understood, call cad_transition(event="cause_understood").
