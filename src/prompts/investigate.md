# Pi-CAD investigate

Current state: INVESTIGATE (read-only).

Form a spatial or engineering hypothesis, then answer it with deterministic probes. Visual questions become targeted measure/frame/section checks. Recipe-native cad_simulate is available when a quantitative physical hypothesis must be tested; author only simulation/**, inspect the controlled Observation, and remember that solve/observe creates no Evidence without cad_commit_simulation. cad_optimize is not available here. If more probing is needed call cad_transition(event="more_probe"). When the cause is understood, call cad_transition(event="cause_understood").
