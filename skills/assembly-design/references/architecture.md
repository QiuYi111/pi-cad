# Assembly architecture

Decompose by function and give each module one purpose. Establish a coordinate spine and name the primary, secondary, and tertiary datum features before authoring part geometry. Record hard envelopes with units.

Write an installation sequence in which every part has an approach direction, a locating feature, a retention operation, and realistic tool access. Check service removal separately; an assembly that can only be built once is not serviceable.

Treat bought-in components as authoritative interface inputs. Preserve their supplier geometry and documented keep-outs instead of remodeling convenient approximations.
