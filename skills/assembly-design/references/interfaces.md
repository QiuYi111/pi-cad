# Interface contracts

Create a contract for every mechanically meaningful module pair, including interfaces that only seal, route, or transfer load.

For each contract state:

- datum features and mating geometry;
- constrained and intentionally free degrees of freedom;
- locating fit, retention method, preload or seal condition;
- assembly direction and tool envelope;
- tolerance ownership and inspection method.

Avoid redundant locating schemes. For example, a face, two close-fit pins, and a rigid bolt pattern can fight unless one feature is relieved. Fasteners retain; they are not automatically precise locators.
