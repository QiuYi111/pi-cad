# Model structure

Separate requirement parameters, interface parameters, derived dimensions, and presentation-only settings. Derive repeated geometry from one source of truth and validate parameter ranges before construction.

Create stable construction frames and datum geometry early. Order features from global massing to interfaces to local details. Keep fillets, chamfers, and cosmetic details late so they do not control upstream references.

Use explicit selectors based on geometry and intent where possible. Avoid relying on transient face or edge indices.
