# Pi-CAD tools

This skill documents the active public surface only. Historical typed inspection and simulation wrappers are not callable.

- Read [references/control.md](references/control.md) for route, record, transition, blocker, review, and finish tools.
- Read [references/model-probe.md](references/model-probe.md) for CAD build, derivations, `cad_probe`, recall, and exports.
- Read [references/simulation-optimization.md](references/simulation-optimization.md) for managed Recipes, explicit simulation commit, and topology optimization.
- Read [references/deliverables.md](references/deliverables.md) for drawings, exports, and rendered presentation assets.

Tool schemas exposed by the harness are authoritative for arguments. These references explain selection, lifecycle, and failure semantics rather than duplicating every schema field.
