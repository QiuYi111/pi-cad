# Mechanical verification

Build verification around failure modes: yielding, buckling, fatigue, wear, fracture, loosening, leakage, excessive deflection, thermal distortion, instability, and misuse as applicable.

Use the least expensive evidence that resolves each claim, escalating from calculation and geometric probe to simulation or physical test. Track uncertainty in loads, materials, tolerances, and model form. A precise solver result is not a substitute for correct inputs.
