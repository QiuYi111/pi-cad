# desktop 与原生版：全面复核

2026-10-11。对照仓库里的现有 Electron desktop 云端模式与 SwiftUI 原生版；初次复核以 `60e10b7` 加工作区代码为快照；下表已更新随后修正。原生版仍未完成。

初版确实只覆盖很小一部分：[原始对比](DESKTOP-PARITY.zh-CN.md) 的 87 项中，11 项已有、23 项部分实现、53 项缺失；设置 16 项中，10 项缺失。这是初版数量，不能拿后续新增代码倒推当时已经交付。

逐项现状见 [87 项进度表](PARITY-PROGRESS.zh-CN.md)。此次重新读了设置、页面导航、模型画布、工作流、记录、CAD 导出及后端调用；检查了原生对应代码和 E2E 覆盖。**有代码、通过本地流程、通过窗口操作、通过真实云端，是四件不同的事。没有完整验收通过的比例。**

Mac 当前锁屏，窗口读取明确被拒绝；本轮未重新打开 desktop 设置或验收新增原生界面。之前真实 GLM 的基础流程通过，不能证明本次新增功能。运行中的旧应用也不能代表刚编译的源码。

## 复核发现及随后修正

1. **已修：当前模型导出可能导错文件。** 画布顶部按 `previewName` 查文件列表，再调用普通下载。两个不同路径可以同名；历史 STEP 被覆盖后也可能下载当前字节。工程结果列表的 `exportArtifact` 已校验所选版本，顶部按钮当时却没使用它。现已从所看网格读取路径与哈希，核对下载字节；同名文件与被覆盖的旧版本经原生流程验证。desktop 导出直接使用当前网格的源路径和保存哈希。对应 V04，系统保存窗口与正式云端仍待验。依据：[原生顶部按钮](Sources/Reify/WorkbenchViews.swift)、[普通导出](Sources/Reify/AppModel.swift)、[版本导出](Sources/Reify/EngineeringActions.swift)、[desktop 导出](../desktop/src/renderer/src/components/CadViewer.tsx)。
2. **已修：保存默认模型后，两处选择可以不同。** 原生 `configure` 只更新模型目录；desktop 还更新当前设置并通知页面。现已同步当前选择、保存偏好与实际助手；失败分别提示云端保存和当前切换结果，原生流程通过。设置窗口、输入框显示及正式云端仍待验。对应 S11/S15/C10。依据：[原生设置操作](Sources/Reify/CloudModels.swift)、[desktop 设置](../desktop/src/renderer/src/pages/Settings.tsx)、[desktop 保存默认](../desktop/electron/main/index.ts)。
3. **已修：刷新会丢自定义配置草稿。** 原生刷新后执行 `custom = app.modelsConfig`；desktop 的目录刷新没有这个赋值。已有 E2E 校验的是错误配置不损坏云端文件，没有测试用户未保存的编辑内容。现已取消刷新时重读配置和覆写编辑内容；新增流程核对缓存内容保留，实际 TextEditor 操作待窗口验。对应 S14/S15。依据：[原生设置](Sources/Reify/SettingsView.swift)、[desktop 设置](../desktop/src/renderer/src/pages/Settings.tsx)。
4. **记录缺失不只是少一个按钮。** 还缺多选、质量/难度/反馈、保存状态、用量、经验整理进度、候选规则、修改文件、验证结果；工作台里的“给当前对话评分”也缺。对应 T01–T05。依据：[desktop 记录页](../desktop/src/renderer/src/pages/Traces.tsx)、[工作台评分](../desktop/src/renderer/src/pages/Workbench.tsx)、[记录后端](../desktop/electron/main/traces.ts)。
5. **Fusion 缺失是 Mac 的功能缺口。** 应补原插件资产、安装/更新、状态与版本、测试导出、当前零件/装配导出、进度/取消、结果目录和失败原因。STEP 下载不能代替在 Fusion 中重建模型和检查结果。依据：[原导出说明](../desktop/src/shared/cad-transfer-guide.ts)、[设置区](../desktop/src/renderer/src/components/CadExportsCard.tsx)、[工作台导出](../desktop/src/renderer/src/components/CadExportButtons.tsx)。
6. **Git 标签已补原生流程，窗口和正式云端待验。** 当前代码读取同一服务器的 desktop 管理员设置，调用原发布后端；默认关闭。已在临时真实仓库核对允许仓库、重复标签、冲突不覆盖、清单与文件损坏拒绝、失败重试、只读及批准撤销拒绝，发布前后源码/索引/当前提交与未跟踪文件保持。完整记录检查已通过。不能为了测试直接向正式仓库推标签。对应 R05。依据：[策略读取](Sources/Reify/DesktopPublishPolicy.swift)、[原生发布](Sources/Reify/PublishActions.swift)、[原后端](../desktop/electron/main/viewer.ts)。

## 原表外的补充检查

**X01：结构分析入口缺失，云端计算能力另列。** desktop 的 CAD 画布仍显示结构分析入口，包含组件状态、材料、载荷、网格、确认和停止；原生没有对应界面。原云端返回“阶段 1 不可用”或“服务器管理”，不能据此宣称完整求解已有，也不能把整个界面从对比中删掉。此项追加核查，不改原始 87 项的历史数量。依据：[分析入口](../desktop/src/renderer/src/components/SimulationLauncher.tsx)、[画布挂载](../desktop/src/renderer/src/components/EngineeringViewer.tsx)、[云端状态](../desktop/electron/main/remote-bridge.ts)。

本地项目目录、WSL、本地 CAD 运行环境不是纯云端客户端必需功能；SolidWorks 是 Windows 专属。Blender、ParaView 和采纳经验规则在现有 desktop 云端明确禁用。**记录、评分、经验整理与重放验证没有被禁用**，不能一并省略。依据：[云端限制](../desktop/electron/main/cloud-mode.ts)、[采纳限制](../desktop/electron/main/traces.ts)、[平台检测](../desktop/electron/main/cad-transfer-detect.ts)。

## 验收缺口与补齐顺序

设置默认同步、配置草稿刷新和画布导出已修。继续补记录、评分、经验整理、重放、Fusion 和分析入口，并完成所有新增窗口/正式云端验收。

每个缺口从 desktop 原入口开始核对操作、调用、返回结果、失败与恢复。E2E 需要实际窗口点击、真实云端和 GLM；模型/图片/工作流/批准/发布须绑定具体项目、对话和版本。新增单元测试不能代替这些验收。

已有本地测试执行真实 Swift 网络、AppModel、原 desktop 解析/批准/打包/重建代码，部分使用真实 Git；测试服务提供账户、助手和 CAD 结果。它们不能发现整页缺失、控件被遮挡、未经专门用例覆盖的导出入口或真实云端兼容问题。最新测试结果另外记录在 [E2E.md](E2E.md)，未测试的项目继续标待验。
